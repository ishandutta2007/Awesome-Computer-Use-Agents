# Awesome-Computer-Use-Agents

# Top Computer Use Agents Ecosystem
**Curated List of SaaS Products & Open-Source GitHub Projects**
*Focused on AI Agents that Control Desktops, Browsers, GUIs, Automate Workflows & Operate Computers Like Humans*
**Last updated: September 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Computer Use Agents**. These AI systems perceive screens (or DOM), plan actions, and control browsers or full desktop environments to complete multi-step tasks on behalf of users.

**Examples** include Perplexity Computer, OpenAI Operator / ChatGPT Agent, Claude (Anthropic Computer Use), Bytebot, and Browser-Use (the category leaders and emerging players).

**Open-source emphasis**: Computer-use and browser agents have a rapidly growing open ecosystem. **Browser-Use**, **Open Interpreter**, self-operating computer frameworks, and related projects let teams run capable agents on their own infrastructure. This section is heavily expanded.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms
- **[Perplexity Computer](https://www.perplexity.ai/)**  
  Perplexity’s computer-use oriented agent capabilities for research and task automation across web and tools.

- **[OpenAI Operator / ChatGPT Agent](https://openai.com/)**  
  OpenAI’s computer-using agent (evolved from Operator) that browses and acts in a virtual environment for end-user and API-driven tasks.

- **[Claude (Anthropic Computer Use)](https://www.anthropic.com/)**  
  Anthropic’s computer-use models and tooling that let Claude see screenshots and control interfaces via tool calls, with strong safety focus.

- **[Bytebot](https://www.bytebot.ai/)**  
  Emerging computer-use / agent platform oriented toward practical desktop and workflow automation.

- **[Browser-Use (Cloud / Hosted)](https://browser-use.com/)**  
  Hosted browser agent and cloud browser offering built on the popular open-source Browser-Use project, with stealth and scale features.

- **[Related agent platforms](https://openai.com/)**  
  Broader category includes other commercial computer-use and agentic browser products from major labs and startups.

## Open-Source GitHub Projects
- **[Browser-Use](https://github.com/browser-use/browser-use)**  
  Leading open-source browser agent framework (Python/TypeScript)—makes websites LLM-friendly, navigates, clicks, fills forms, and completes web tasks; MIT licensed with optional cloud.

- **[Open Interpreter](https://github.com/OpenInterpreter/open-interpreter)**  
  Open-source local agent that writes and executes code, controls the browser, and operates the computer via natural language.

- **[Self-Operating Computer Framework](https://github.com/OthersideAI/self-operating-computer)**  
  Open framework enabling multimodal models to operate a computer through screenshots and mouse/keyboard actions.

- **[open-browser-use / open-computer-use projects](https://github.com/)**  
  Platform-neutral open browser and computer-use layers with CLIs and SDKs for agent integration without lock-in.

- **[UI-TARS and GUI agent models](https://github.com/)**  
  Open GUI agent approaches focused on human-like perception, reasoning, and action on graphical interfaces.

- **[Playwright / Selenium agent wrappers](https://github.com/microsoft/playwright)**  
  Browser automation foundations widely used as the execution layer under open computer-use agents.

- **[MCP browser and desktop servers](https://github.com/)**  
  Model Context Protocol servers that expose browser and desktop control to LLM agents in a standardized way.

- **[Multi-agent browser systems (OpenManus, nanobrowser, etc.)](https://github.com/)**  
  Community multi-agent projects built on or inspired by Browser-Use for complex web workflows.

- **[Local LLM + computer-use stacks](https://github.com/)**  
  Patterns combining Ollama/local models with open browser and desktop agents for fully offline operation.

- **[Documentation and Browser-Use / computer-use playbooks](https://docs.browser-use.com/)**  
  Guides for running self-hosted agents, choosing models, and securing computer-use sandboxes.

### Additional Strong Open-Source Options
- Running **Browser-Use** locally or with your own cloud browsers for web automation.
- Using **Open Interpreter** when code execution and local file access are primary.
- Combining screenshot-based computer-use frameworks with frontier or local VLMs.
- Accepting that managed safety guardrails, hosted virtual machines, consumer-grade reliability, and enterprise support still favor commercial offerings (Claude Computer Use, OpenAI agents, Perplexity, hosted Browser-Use, etc.).
- Focusing open-source efforts on data control, cost at scale, customization, and research.

**Frameworks for building custom systems**: Choose Browser-Use or a screenshot-based computer-use framework → pair with a strong VLM/LLM → sandbox the agent (browser-only or full desktop VM) → add human approval gates → log actions for audit. Suitable for developers and automation teams. Production consumer products often rely on lab-hosted agents for safety and UX.
